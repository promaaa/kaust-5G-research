# Documentation guide

This directory contains the public research record. The material is a mixture
of synthesis documents, chronological lab reports, working notes, diagrams, and
presentation sources.

## Recommended reading order

1. [Project synthesis](Notes/5G_CU_DU_Research_Summary.md) — architecture,
   milestones, and earlier setup notes.
2. [Progress-report index](Presentation/README.md) — the chronological record
   and the late-stage results that supersede early hypotheses.
3. [Reproducibility guide](REPRODUCIBILITY.md) — what is and is not currently
   repeatable from this repository.
4. [Literature](References/README.md) — links to the papers used to position the
   work.
5. [Scientific-publication assessment](analysis/scientific-publication-assessment.md)
   — a working document, not a peer-reviewed conclusion.

## Canonical versus historical material

The progress reports intentionally preserve the sequence of the investigation.
Early reports contain hypotheses and interim measurements that later reports
refine or overturn. For current performance and root-cause claims, prioritize
Reports 18–22 and the root README.

The deployment code, exact OAI patch set, runtime configuration files, and raw
experiment data are not currently included here. Consequently, this repository
documents the work but is not yet a complete clean-room reproduction artifact.

## Viewing the vault

front matter. Local settings, downloaded plugin code, and per-user workspace
